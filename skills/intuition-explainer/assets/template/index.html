The local slopes describe height changes here. A step can move away from the minimum in one coordinate while the combined change in both coordinates lowers the height. Local steepness is different from a straight route to the bottom.

These bowls each have one minimum. Real losses can have many valleys, noisy slopes, and millions of coordinates.

About this model What is computed, and what is simplified?

Computed. Every height, local slope, update, contour, and prediction result comes from the current inputs. The plotted path is actual gradient descent. Displayed values are rounded; updates use full floating-point precision.

Simplified. One- and two-dimensional convex quadratic functions, exact gradients, and a fixed step size. There is no training dataset, noise, momentum, adaptive optimizer, or claim about real model performance.

Assumed. Starting positions, curvatures, step sizes, and Euclidean coordinates are teaching choices. A run stops past coordinate magnitude 10⁶ or 72 recorded steps for browser usability; that is a guard, not convergence.

Illustrative. Animation speed and frames between recorded steps are visual aids, not extra optimizer steps. The amber uphill arrow on a map shows direction at a scaled length; the teal next-step arrow uses the calculated displacement. The view fits a revealed experiment and labels its axes. Curve axes can have different scales; the contour map uses equal scales.

The exact functions and gradients

Bowl: f(x) = x²/2, slope = x. Narrow valley: f(x,y) = (x² + 4y²)/2, gradient = (x, 4y).

Rotated valley: dx = x + 0.8, dy = y − 0.4, θ = π/5. Let u = cos θ · dx + sin θ · dy and v = −sin θ · dx + cos θ · dy. Then f = (0.6u² + 5v²)/2. The gradient is (0.6u cos θ − 5v sin θ, 0.6u sin θ + 5v cos θ), by the chain rule.

All updates subtract the step size times this gradient. This lesson teaches how to use a local slope, not how to derive derivatives.
